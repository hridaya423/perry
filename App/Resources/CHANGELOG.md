# Perry 1.0

Perry’s live session now moves through a real screen selection, click-advanced teaching, supervised sandbox work, independent verification, and searchable local history.

Voice input shows partial transcripts, supports push-to-talk from any app, cuts in cleanly when you speak, and falls back to a built-in microphone or clipboard reply when hardware fails.

The agent strip keeps the work visible with trust tiers, a five-second cancel window, pause, steer, retry, and verification results.
