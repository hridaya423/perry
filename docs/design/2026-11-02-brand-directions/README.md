# Perry brand directions

Four imagegen concept boards, made 2026-11-02 with the built-in image generation tool. The app and existing brand assets are unchanged. The Perry name stays in all directions.

Palette values above are intended specifications. Rendered shaded materials do not equal uniform color chips. The second-round boards omit hex captions; this table retains the exact specifications.

## What was refined

The first pass produced four coherent boards, but three relied on P-shaped marks and the compositions were too similar. Hotwire's ordinary P became an elastic tool silhouette. Foldspace's conventional metallic P became a folded screen bracket. Their second compositions also differ from the first-round object-and-logo arrangement. Both rounds remain here for comparison.

All six generated images were visually inspected in this session. The four selected PNG files were decoded and checked: 1536 x 1024 pixels, fully opaque. Those checks establish artifact integrity, not production icon legibility or trademark clearance. Small marks in these images are conceptual reductions. Vector construction, exact typography, actual 16 px rendering, accessibility contrast and user recognition have not been verified.

## Source material and prompts

Product evidence: repository README.md, DESIGN.md, current 512 px app icon. Perry sees the screen, teaches by pointing and drawing, and can perform tasks. The user's request opens all visual identity decisions and rejects the current sage droplet.

Reference studies: [Orvo poster](https://cdn.recent.design/items/buxddnx/0/image/8ad34d1d48c1b02a1ab5/2048.webp), for the interaction between material and type; [Geist Serif poster](https://cdn.recent.design/items/2q002o2/0/image/6209c1d150fc52920835/2048.webp), for a transformation repeated as a graphic grammar. Both were downloaded and inspected. Inspora's fetched page supplied no inspectable design reference. References are study material, not incorporated assets.

The complete generation prompts are in [prompts.json](prompts.json) and [prompts-refinement.json](prompts-refinement.json). No external model API or CLI fallback was used.
