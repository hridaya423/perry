# Perry concept refinement

Concepts generated with the built-in imagegen tool on 2 October 2026. These are design references, not implemented screens.

The selected onboarding direction is the ivory handwritten hello with Perry tucked into its final letter. The next implementation should animate the greeting once, then settle.

The user rejected the tall Your Perry navigation list. The revised expanded workspace uses a wide composition with saved assistants and recent conversations in a compact left rail, a central voice action, and secondary task, routine and file navigation along the bottom. This is an expansion of the notch, not a separate Home window.

Listening belongs beside the native cursor as three small bars. Working status and completion can use a compact adjacent capsule. Results, approvals and browsing expand in the notch. Do not enlarge or replace the native pointer.

## Review notes

Imagegen still approximates hardware geometry. The implementation must use an opaque black crown at the physical display top, an empty camera reserve, concave shoulders and rounded lower corners. The workspace render removes the visible menu bar; the actual app must preserve system menus outside its bounds. Cursor feedback must avoid covering the user's target. The approval's Undo promise is valid only for operations backed by a verified undo mechanism.

No implementation edits were made during this concept refinement. Existing repository changes predate it.
