# Notch variations

The user selected round 8, concept 2, “Someone in the notch.” These four variations keep its expanded black notch, brush greeting, stick mascot and explicit Mac assistant positioning.

Generated with the built-in imagegen tool using the selected image as a reference. Generation and visual inspection are in progress.

1. Perched: closest refinement, with Perry seated on the notch and helping group files.
2. Peekaboo: asymmetric composition, with a larger Perry peeking from the edge and pointing into Preview.
3. The unfolding notch: a folded paper corner gives Perry a ledge above the app demonstration.
4. After hours: cobalt paper desktop, black notch and dark native UI.

These are illustrative website concepts, not functioning product screenshots. Full prompts are in prompts.json. Any website demo would run in a contained simulation.
